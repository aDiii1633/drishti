# Evaluator Workspace Status

The evaluator sidebar contains only Home, Profile, Assigned Papers, and Help.

Assigned Papers reads the existing evaluator assignment records server-side. Start Checking continues to open the existing marking workspace with the selected bundle ID. The evaluator profile now reads subject and centre information from the linked evaluator profile record when available.

Object-level bundle authorization remains enforced by the backend: an evaluator can view only a bundle assigned to that evaluator.
