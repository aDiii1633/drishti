# DRISHTI Design System

## Direction

The supplied reference was used for its calm application density, simple line iconography, refined typography hierarchy, subtle borders, and restrained surfaces. DRISHTI retains its own name, sky-blue operational palette, and content.

## Typography

- UI: Inter
- Display headings: Instrument Serif
- Metadata: DM Mono

`client/src/index.css` centralizes the typography scale, line heights, semantic colors, spacing, radii, shadows, focus treatment, panels, navigation, inputs, and interaction timing. Letter spacing is intentionally neutral.

## Components

Lucide is the single application icon family. Controls use a compact 8px radius, white or subtle-blue surfaces, visible focus rings, and semantic success/warning/danger tokens. Cards use a one-pixel border with a restrained shadow; sidebars, tables, forms, status pills, and authentication screens inherit this same system.

## Accessibility and responsive behavior

Focus indicators are visible for all keyboard-operable controls. Existing responsive grids and workspace layouts are preserved, including the full desktop evaluator workspace and collapsed mobile navigation.
